When Venpadi sends you an SMS

Venpadi uses SMS for one thing only: proving that a phone number belongs to the person using it. Verification is required at these stages, and nowhere else.

  1. Creating an accountYou enter your number on this page or in the app, we text a 4-digit code, and the account is only created once that code checks out.
  2. Signing in on a new phoneChanging or replacing your phone means proving the number is still yours, so a fresh code is sent before your records are restored.
  3. Recovering accessAfter too many wrong PIN attempts the app stops deciding locally and asks for a code instead.

Sender ID: VENPADI

Your Venpadi code is 1234. It expires in 5 minutes. Do not share it with anyone.

  • The code is 4 digits and expires 5 minutes after it is sent.
  • One code per number per minute, and at most 5 per hour.
  • Five wrong attempts close the code; you request a new one.
  • Codes are stored only as hashes and are never shown to our staff.

Venpadi never sends marketing or promotional SMS, and never texts your customers. Debt reminders stay inside the app, on your own screen.
